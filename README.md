# SignSetu / SignSpeak AI 🤟

A voice-first sign language-to-speech translator designed to bridge communication gaps for deaf and mute individuals.

## Live Demo
[Try SignSetu Web App](https://sign-speak-translator--skajle700.replit.app)

## Features
- **Real-time Gesture Recognition:** Uses Gemini 1.5 Flash Vision API to analyze hand gestures.
- **Hindi Speech Synthesis:** Converts translated text directly into spoken Hindi audio via Web Speech API.
- **Simple & Accessible UI:** Fast, mobile-friendly interface designed for effortless operation.

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- AI Model: Gemini 1.5 Flash (Vision)
- Speech Engine: Browser Web Speech API (TTS)
